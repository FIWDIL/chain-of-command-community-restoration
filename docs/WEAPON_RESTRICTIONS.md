# Choosing weapons

In **Offline vs CPU** or **Host**, choose the number of machine guns and SMGs for each side. The same quantities go to both sides. Remaining soldiers receive rifles.

USA uses Garand rifles, BAR machine guns and Thompson SMGs. Germany uses Mauser rifles, MG42 machine guns and MP40 SMGs.

Each four-soldier fireteam can have at most one machine gun and two SMGs. The game supplies a starting distribution. Before launch, Equipment lets the host or a fireteam's commander move weapons between individual soldiers. Return a weapon to the side stockpile by choosing Rifle before assigning it elsewhere. A new player takes over existing soldiers and equipment.

You can change these settings, including choosing zero special weapons for a rifles-only game.

The per-fireteam limits come from the recovered game data. The starting quantities above are restoration choices: the lost server's original allocation rules are unknown. [Recovered weapon data](recovered-weapon-rules.json) records the supporting fields and file hash.
