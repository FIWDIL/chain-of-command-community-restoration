# Chain of Command community restoration

This repository is the active source for the original-engine community restoration. Work in this Git working tree for future restoration changes. Its existing origin is https://github.com/Huckleberry87/chain-of-command-community.git.

Combat on Contact is a separate project. Do not mix its Godot source or assets into this repository.

Keep path handling relative to this repository root. Local recovered game files in game/ are intentionally ignored by Git; they accompany release packages. Preserve their original bytes. See README.md for running, testing and packaging.
